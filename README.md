# Camera Health Monitor

Camera Health Monitor is a Kotlin application that simulates monitoring of IP cameras in a surveillance system.

## Features

- Online / offline monitoring
- Latency measurement
- Signal quality estimation
- Camera health reports
- Dashboard statistics
- Console output
- Modular architecture

## Project Structure

```
config/
models/
services/
utils/
resources/
```

## Build

```bash
./gradlew build
```

## Run

```bash
./gradlew run
```
